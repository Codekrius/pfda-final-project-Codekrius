## Title
Flapping Avian

## Repository
https://github.com/Codekrius/-pfda-final-project-Codekrius

## Description
My goal for this program is to create a clone of flappy bird entirely in pygame. This will be a good challenge for me because it'll test my coding/research skills pertaining to pygame, and will be fun interactive game to share with friends.

## Features
- Start Menu
	- A simple start menu that will prevent the game loop from activating until the player presses the spacebar.
- Bouncing Player Character
	- An avian with a square hitbox that is affected by gravity and the player is able to move up by flapping (pressing spacebar).
- Obstacles
	- Kill spaces that prevent the player from having their avian from breaking out of bounds, and obstacles that come at the player and they must dodge by flapping.

## Challenges
- How to detect input from the player.
- How to detect collision in pygame.
- How to implement more image assets and shapes into pygame.

## Outcomes
Ideal Outcome:
- A functional and optimized clone of flappy bird with custom assets.

Minimal Viable Outcome:
- A functional clone of flappy bird.

## Milestones

- Week 1

- Week 2
  1. Create kill bounds for the top and bottom of the map.
